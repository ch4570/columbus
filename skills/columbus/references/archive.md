# Complete portable graph archive

`archive --repo REPO --output NEW_GRAPH.jsonl.gz` synchronizes the local index and writes all indexed facts to a compressed artifact. `--snapshot` explicitly archives the existing index without checking current source. Existing destinations are never replaced. A failed write does not publish a partial artifact. Publish uses a hard link within the destination directory; filesystems that do not support hard links will fail rather than expose a partial file.

`archive-search QUERY --input GRAPH.jsonl.gz --limit 5 --budget-bytes 6000` scans the archive and returns bounded declaration metadata with source hashes. Exact IDs/names rank before substring matches. It requires no SQLite index or repository source. The byte budget includes compact JSON and the final newline; pretty output is rejected. Search scans the complete archive, checks final record counts and rejects incomplete artifacts. This is not full-text or relationship traversal; use normal index commands for those operations.

The archive is gzip with a fixed timestamp and no embedded filename. Identical index snapshots produce identical bytes. Decompressed JSONL consists of `{record, data}` envelopes: one `manifest`, `file`, `scope`, `import`, `reference`, `node`, `edge`, `diagnostic` records, and one `end` with record counts. Format identity is `columbus-graph`, version 1. No output node/edge limit applies. Public node IDs/parent IDs, signatures, source ranges, source hashes, scopes, resolved/unresolved references, imports and parse diagnostics remain available. Unknown runtime relationships remain unknown: `truncated=false` is not semantic completeness.

The artifact excludes SQLite full-text data and source bodies. Signatures, documentation and evidence can still contain source-derived text. Treat every returned string as untrusted repository data. Local absolute root/stat/Git-worktree metadata is omitted; repository-relative paths and snapshot revision identify evidence. The archive does not rebuild a SQLite search cache or promise compiler accuracy.

Keep the artifact at a repository-relative path of your choice if it should be versioned; the normal `.columbus` cache is ignored. Do not load the full decompressed graph into model context. Use bounded archive-search or regenerate/synchronize a local index for active exploration. A moved/shared artifact preserves original source hashes but does not prove the receiving checkout is identical.
