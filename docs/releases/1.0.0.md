# Columbus 1.0.0

콜럼버스가 코드의 지도를 펼칩니다. 저장소·명령·패키지·스킬을 Columbus 이름으로 통일하고, 나침반과 지도를 든 탐험가 캐릭터, 재현 가능한 벤치마크 그래프를 함께 담았습니다.

## 설치와 첫 탐색

Python 3.11 이상과 uv가 필요합니다. 설치 후 탐색할 프로젝트 디렉터리에서 실행하세요.

```sh
uv tool install https://github.com/ch4570/columbus/releases/download/v1.0.0/columbus-1.0.0-py3-none-any.whl
columbus explore
columbus explore checkout --session checkout
columbus stats checkout
```

pipx를 쓰면 `uv tool install`을 `pipx install`로 바꾸세요. Python만 있다면 `get-columbus.py`를 내려받아 실행하면 됩니다. 설치기는 wheel 체크섬과 실행 환경을 확인한 뒤 명령을 연결합니다. [설치 가이드](https://github.com/ch4570/columbus/blob/v1.0.0/INSTALL.md).

## 포함한 기능

- 66개 언어 감지 프로필, Python·Java·Kotlin AST, 43개 선언 휴리스틱과 UTF-8 텍스트 검색.
- 증분 SQLite 색인, 심볼·호출·임포트·상속 관계 탐색과 제한된 크기의 소스 조회.
- `explore`, 작업별 `--session`, `stats`: 필요한 코드 탐색, 중복 소스 제외, 실제 응답량 확인.
- JSON·Mermaid·GraphML·오프라인 HTML 그래프와 선택형 MCP.
- 새 캐릭터 이미지와 영어·한국어 README, 벤치마크 JSON·그래프·생성 스크립트.

## 벤치마크를 읽는 법

Columbus 1.0의 CLI 응답량과 증분 색인은 실제 실행한 데이터로 그래프를 만들었습니다. 이전 RepoAtlas 0.4.0의 실제 Codex 탐색도 별도로 보여줍니다. 도구 출력 바이트와 실제 모델 입력 토큰은 다른 측정입니다. 이전 실험에서 양쪽 인용이 통과한 사례는 입력이 34.0% 증가했으며, 일반적인 모델 토큰 절감을 입증했다고 주장하지 않습니다. [그래프·원본·재현 방법](https://github.com/ch4570/columbus/blob/v1.0.0/docs/benchmarks/README.md).

## 프리뷰에서 이전하기

새 명령은 `columbus`, 스킬은 `.agents/skills/columbus/`, 색인은 `.columbus/index-v1.sqlite`입니다. 사용자 설정은 `.columbus.json` 또는 `.columbusignore`로 옮기세요. 이전 `.repoatlas/`와 스킬 설치는 자동 변경하지 않습니다. 새 색인과 세션으로 시작합니다.

## 배포 파일과 검증

`columbus-1.0.0-py3-none-any.whl`, `columbus-1.0.0.zip`, `get-columbus.py`, `SHA256SUMS.txt`를 제공합니다. wheel은 CLI·스킬을, ZIP은 문서·예제·테스트·벤치마크 근거까지 포함합니다. Ubuntu·macOS·Windows와 Python 3.11·3.14의 6개 CI 작업을 통과했습니다. Ubuntu·macOS의 4개 조합에서 각각 230개, Windows 3.11에서 229개, Windows 3.14에서 228개 테스트가 통과했습니다. Windows에서는 POSIX 전용 검사 1개를 제외하며, Python 3.14에서는 호환되지 않는 과거 RepoAtlas 0.4 재현 검사 1개도 제외합니다. 현재 Columbus 엔진과 실제 배포 검사는 모두 실행했습니다. 최신 실행 근거와 플랫폼별 범위는 [검증 기록](https://github.com/ch4570/columbus/blob/v1.0.0/VALIDATION.md)에 정리합니다.
