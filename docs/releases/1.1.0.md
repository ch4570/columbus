# Columbus 1.1.0 — 미배포 후보

아래 1.1.0 다운로드·태그 링크는 릴리즈 게시 이후에 사용할 수 있습니다. 현재 후보는 [체크아웃에서 설치](../../INSTALL.md#from-a-checkout-or-local-wheel)할 수 있습니다.

AST 그래프를 압축 파일로 레포에 보관하고, 소비자 SQLite 없이 필요한 선언과 관계를 조회할 수 있습니다. Java 호출 해석의 잘못된 연결을 줄이고, 지원하지 않는 관계는 미해결 상태로 남깁니다.

## 설치와 그래프 보관

Python 3.11 이상이 필요합니다. uv 대신 pipx를 사용하거나 [Python 설치기와 ZIP 설치 방법](https://github.com/ch4570/columbus/blob/v1.1.0/INSTALL.md)을 따를 수 있습니다. 설치 후 그래프를 보관할 프로젝트 디렉터리에서 나머지 명령을 실행합니다.

```sh
uv tool install https://github.com/ch4570/columbus/releases/download/v1.1.0/columbus-1.1.0-py3-none-any.whl
columbus init
columbus archive --repo . --output codegraph/graph-v1.jsonl.xz --compression xz
columbus archive-search Class.method --input codegraph/graph-v1.jsonl.xz --format text --budget-bytes 6000
```

`Class.method`는 프로젝트의 선언 이름으로 바꿉니다. 그래프는 `.columbus/` 밖의 새 경로에 저장해 Git으로 관리합니다. 기존 출력 파일은 덮어쓰지 않습니다. [전체 사용법](https://github.com/ch4570/columbus/blob/v1.1.0/docs/portable-graph-workflow.md).

## 포함한 변경

- 여러 선언의 원문을 한 번에 읽는 `archive-source` 일괄 조회. 겹치는 줄을 한 번만 반환하고 전체 출력에 같은 바이트 예산과 페이지 커서를 적용합니다.
- 전체 gzip/XZ 그래프 아카이브와 제한된 크기의 선언 검색, 관계·호출자 조회. 같은 체크아웃이 있으면 저장된 해시를 검증해 선언 본문도 읽습니다.
- 부모 관계와 소스 위치를 보존하는 AST JSONL 트리, 프로젝트에 설치하는 에이전트 스킬, 명시적으로 설정하는 pre-commit·Git 갱신 훅.
- 파싱 사실과 검색 문서를 압축하는 schema 4 캐시, 변경되지 않은 사실의 재사용, 그래프·검색을 함께 갱신하는 트랜잭션.
- Java 이름 공간·접근성·인자·상속·enhanced-for/getter 해석 보완. getter 반환 타입의 선언 패키지를 유지하고 `this` 인자의 불일치를 차단합니다.
- Python 인스턴스 수신자의 어휘적 후보는 선택형 `candidate_calls`로 구분합니다. 정적 호출로 확정하거나 런타임 디스패치를 증명하지 않습니다.
- 스킬의 아카이브 탐색, 소스 페이지 읽기와 연속된 원문 인용 안내.
- JSX/TSX 요소의 일반 텍스트에서 가짜 호출·선언을 만들지 않도록 수정하고, 지원되는 내장 코드 표현식은 계속 추출합니다.

## 호환성과 분석 범위

schema 2/3 캐시는 읽을 수 있으며 다음 동기화에서 schema 4로 원자적으로 업그레이드됩니다. 구버전 엔진은 schema 4를 거부하므로 버전 비교나 복귀에는 별도 `--db` 경로를 사용합니다. 기존 SQLite 파일은 업그레이드만으로 작아지지 않을 수 있습니다.

gzip이 기본 형식이며 XZ는 선택 사항입니다. XZ는 저장 공간을 줄이는 대신 반복 조회 시 압축 해제 비용이 커질 수 있습니다. 아카이브에는 전체 저장 그래프와 미해결·진단 정보가 포함되지만 소스 본문과 SQLite 검색 캐시는 포함되지 않습니다. 소스 없는 그래프 조회는 소비자 체크아웃의 최신 상태를 검증하지 않습니다.

Python·Java·Kotlin은 AST를 사용합니다. 다른 지원 프로필은 휴리스틱 또는 텍스트 수준이며 언어 감지가 완전한 호출 해석을 뜻하지 않습니다. JSX도 어휘적 휴리스틱이며 `await` 뒤의 JSX나 제네릭 컴포넌트 등 지원되지 않는 형태는 잘못되거나 누락된 사실을 만들 수 있습니다. 생성 코드, 외부 의존성, 동적 디스패치와 지원되지 않는 타입 변환은 여전히 공백으로 남을 수 있습니다. [언어별 범위](https://github.com/ch4570/columbus/blob/v1.1.0/docs/languages.md).

**일반 배포는 upstream `tree-sitter-java==0.23.5`를 유지합니다.** 애너테이션 파싱을 수정한 실험용 `0.23.5+columbus.1` 후보와 후보를 포함한 ZIP은 별도 검증 산출물입니다. 이 릴리스의 wheel·일반 ZIP·설치기는 후보를 기본으로 배포하지 않으므로 후보의 파싱 개선을 일반 배포 결과로 주장하지 않습니다.

## 검증과 토큰 사용량

검증 근거는 엔진 회귀 테스트, 컴파일러 대조군, 증분·새 색인의 동일성 검사, 실제 wheel·ZIP 설치와 이동 검사로 나눠 기록합니다. 게시 워크플로는 최종 태그에서 Ubuntu·macOS·Windows와 Python 3.11·3.14의 6개 배포 작업을 실행하고, 성공 후 버전·체크섬을 확인해 자산을 게시합니다. [이번 후보의 다국어·회귀 결과](https://github.com/ch4570/columbus/blob/v1.1.0/evals/release-v1.1.0/REPORT.md), [검증 기록](https://github.com/ch4570/columbus/blob/v1.1.0/VALIDATION.md)과 [구현·평가 보고서](https://github.com/ch4570/columbus/blob/v1.1.0/docs/goal-progress.md)에서 실제 실행 범위와 미완료 기준을 확인할 수 있습니다.

**실제 모델 토큰 절감은 입증되지 않았으며 릴리즈 필수 조건입니다.** [Java·Kotlin/Java·JavaScript 비교 6쌍](https://github.com/ch4570/columbus/blob/v1.1.0/evals/multilang-token-batch/ANALYSIS.md)은 모두 실제 입력·출력이 늘어 실패했습니다. 12회 실행을 모두 완료했고 Columbus 실행 6회 모두 일괄 소스 조회를 사용했지만, 전체 품질과 토큰 절감을 함께 충족한 쌍은 없습니다. 따라서 병합·태그·릴리즈를 진행하지 않았습니다. [최근 비교 11쌍](https://github.com/ch4570/columbus/blob/v1.1.0/evals/model-usage-overview/REPORT.md)에는 기존 품질을 유지하면서 전체 입력·출력을 줄이는 합격 조건을 충족한 쌍이 없습니다. 파일 압축률, 도구 응답 바이트와 모델이 보고한 토큰은 각각 별도로 측정합니다. 이 릴리스는 일반적인 토큰 절감이나 모든 언어의 의미적 완전성을 주장하지 않습니다.

## 배포 파일

`columbus-1.1.0-py3-none-any.whl`, `columbus-1.1.0.zip`, `get-columbus.py`, `SHA256SUMS.txt`를 준비합니다. wheel은 CLI와 설치 가능한 스킬을, ZIP은 소스·문서·예제·테스트·평가 근거를 포함합니다. Python과 모든 플랫폼의 의존성 wheel을 포함하는 오프라인 배포는 아닙니다. 최초 설치에는 패키지 인덱스 접근 또는 대상 환경에 맞게 준비한 wheelhouse가 필요합니다.
