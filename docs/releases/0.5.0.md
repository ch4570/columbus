# RepoAtlas 0.5.0

설치한 뒤 `repoatlas explore`로 바로 저장소를 살펴보는 첫 비공개 프리뷰 릴리스입니다. 코드 그래프, 작업별 컨텍스트, 관측 결과를 함께 제공합니다.

## 시작하기

탐색할 프로젝트 디렉터리에서 실행하세요. 저장소 접근 권한, 로그인된 GitHub CLI, Python 3.11 이상과 uv가 필요합니다. 릴리스 페이지에서 직접 wheel을 내려받아도 됩니다.

```sh
gh release download v0.5.0 --repo ch4570/repo-graph --pattern 'repoatlas-0.5.0-py3-none-any.whl'
uv tool install ./repoatlas-0.5.0-py3-none-any.whl
repoatlas explore
repoatlas explore checkout --session checkout
repoatlas stats checkout
```

pipx 사용자는 `uv tool install`을 `pipx install`로 바꿀 수 있습니다. Python만 있다면 아래 자산에서 `get-repoatlas.py`, wheel, `SHA256SUMS.txt`를 내려받아 `python3 get-repoatlas.py --wheel ./repoatlas-0.5.0-py3-none-any.whl --checksum-file ./SHA256SUMS.txt`로 실행하세요. Windows에서는 `python3`를 `py -3`로 바꿉니다. 설치기가 사용자 전용 환경을 만들고 명령 위치를 안내합니다.

저장소 공개 범위는 비공개로 유지합니다. 제품 이름과 브랜딩 정리 후 공개 여부를 별도로 결정합니다.

## 포함한 기능

- Python·Java·Kotlin AST, 43개 선언 휴리스틱을 포함한 66개 언어 감지 프로필과 미지원 UTF-8 텍스트 검색.
- 증분 SQLite 색인, 심볼·관계·영향 탐색, JSON·Mermaid·GraphML·오프라인 HTML 그래프.
- `explore [QUERY]`: 자동 색인, 읽기 쉬운 text, 기본 2,000 추정 토큰. 기존 JSON 명령과 선택형 MCP 7개 도구 유지.
- `--session NAME`: 중복 소스 범위를 제외하고 남은 코드를 이어 읽는 receipt와 로컬 metadata 기록. `stats NAME`으로 집계.
- 긴 함수의 관련 부분 발췌, 정확한 이름 검색의 헤더 유지, 원본·디코딩 해시를 함께 검증하는 최신성 검사.
- 체크섬을 확인하는 Python-only 설치기, 사용자 전용 venv, 기존 명령을 보존하는 업데이트, 오프라인 wheelhouse 지원.

## 관측 결과

README에 결과와 한계를 직접 담았습니다. 0.4.0 예제 측정에서 같은 28개 지도 항목의 응답은 JSON 대비 text가 **46.8% 작았고**, 같은 context 세 번의 전체 응답은 receipt 사용 시 **53.5% 줄었습니다**.

실제 Codex 탐색 6회에서는 일반적인 모델 토큰 절감을 입증하지 못했습니다. 양쪽 답변이 인용 검사를 통과한 사례에서는 누적 입력이 **34.0% 증가**했습니다. 초기 빈 색인 실험과 인용 실패도 보존했습니다. 0.5.0의 세션 편의 기능에 새로운 모델 토큰 절감률을 붙이지 않습니다.

## 배포 파일

- `repoatlas-0.5.0-py3-none-any.whl`: uv·pipx·전용 venv에 설치하는 CLI와 스킬.
- `repoatlas-0.5.0.zip`: 설치 코드·문서·예제·테스트·관측 근거를 포함한 소스 번들.
- `get-repoatlas.py`: pipx/uv 없이 실행하는 사용자 설치기.
- `SHA256SUMS.txt`: 위 세 파일의 SHA-256.

이번 비공개 프리뷰는 로컬 테스트 **208개**와 macOS·Linux의 Python 3.11·3.14 설치 검증을 마친 산출물을 수동 게시합니다. [GitHub Actions](https://github.com/ch4570/repo-graph/actions/runs/34094599664)는 계정 결제 또는 사용 한도 문제로 작업 시작 전에 차단됐습니다. 원격 CI 및 Windows 통과를 주장하지 않습니다. 자동 정식 릴리스 워크플로는 태그·패키지 버전 확인과 6개 플랫폼 검증을 여전히 요구합니다. 분석 수준은 언어에 따라 AST·heuristic·text로 다르며 모든 런타임 호출을 증명하지 않습니다.
