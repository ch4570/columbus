# Saved-graph evaluation requirements

Prior model pairs evaluated a prebuilt SQLite index, not the user's repository-stored graph workflow. They remain failed or non-saving results and are not reclassified by new archive support. The next evaluation must separate a saved-graph condition from the existing index condition.

Prepare a new task before inspecting its answers. Both conditions receive an identical immutable source snapshot. The archive condition additionally receives one complete versioned archive and the frozen current skill/runtime; the local SQLite used to produce that artifact must be absent from the trial consumer. Baseline uses ordinary source tools without graph data. Do not suggest expected target IDs, caller counts or source paths in the prompt. The archive should sit outside the common source tree so baseline source manifests remain identical. Record its hash, codec, source hashes, producer revision and complete record counts. Include archive export/index costs separately from actual model usage.

Preflight must verify source and runtime manifests, exact archive checksum, absence of a consumer index, and archive/source hash agreement before and after trials. Corrupted, replaced or stale artifacts must fail preflight before model launch. A saved graph must not be called fresh merely because its compressed bytes are unchanged. The shared harness currently requires live_index_preflight, so it does not meet these requirements without an explicit archive mode; do not bypass that gate with forged index metadata.

Freeze a different task and independent oracle, semantic/citation gate, model, order and timeouts before calls. Require both answer-quality gates before accepting a token comparison. Measure total/cached/uncached input, output, command bytes and actual archive-tool use. One correct small archive does not prove lower model token usage. No task target is selected and no model run is started by this requirements document.

preflight.py now implements a read-only archive gate with full source/runtime manifests, compressed checksum, source hashes from every file record, complete record counts, producer revision and absence of consumer index directories. It rechecks input hashes after scanning and never starts a model. test_preflight.py exercises both codecs and rejects residual indexes, source/runtime changes, stale graph hashes even when the expected source manifest is updated, count mismatches and corrupted compressed bytes. The local unittest passes. This gate is not yet connected to observe.py's trial runner; a saved-graph model condition remains unavailable until that integration and its invocation tests are complete.
