# Verified source context from a saved graph

`archive-neighbors --kinds calls --context-lines N --repo REPO` now returns source excerpts around the emitted call sites without a consumer SQLite index. N is a radius from 0 through 40. JSON exposes call_context; text prints physical line numbers. This combines relationship lookup, source hashing and bounded excerpt retrieval, which were separate commands in the archived model traces.

Each file is read stably and must match the archived source hash before any excerpt is returned. Nearby ranges merge within the lexical source declaration. Separate edges and repeated same-line calls remain distinct, including in call_lines. Context is recomputed for retained edges as the byte cap shortens a page. The cap includes context and final output formatting. Follow next_offset; increasing the radius can require more pages or a larger budget.

This verifies returned source bytes, not the entire graph's current freshness or runtime completeness. Default archive queries remain source-free. Missing/stale files, paths outside the repository, invalid radius/kind combinations and call sites outside their declarations fail. The archive format and source-free storage size are unchanged. Source bodies are read from the supplied checkout, never embedded into the archive by this feature.

On the unchanged frozen Django archive, text with radius 2 and a 12,000-byte page budget returns all 23 stored incoming edges in two pages (11 and 12 edges), including matching excerpts from 11 files. Total output is 22,450 bytes. Its 22 production call sites and 14 lexical callers match the independent AST oracle; the remaining edge is a top-level test caller. Every returned source range was reconstructed from source and compared exactly, and the archive hash remained unchanged. The consumer has no SQLite index.

These numbers are a functional diagnostic, not a token or latency comparison. The prior plain-graph measurement used a different page budget and did not return source. Radius 2 is insufficient to explain every caller's full control flow, so further source inspection may still be necessary. No failed model pair was replayed and model token savings remain unproven.
