# Relational pilot: no demonstrated graph-token saving

Both predeclared trials completed without timeout, with unchanged source and matching requested model/settings. Neither passed the citation gate. Neither invoked a graph command. The Columbus condition read the reduced skill and then used shell/source navigation. Therefore lower observed input cannot establish a quality-preserving graph benefit.

| Measure | Baseline | Columbus available |
| --- | ---: | ---: |
| Input tokens | 145,388 | 79,827 |
| Cached input subset | 107,392 | 43,520 |
| Uncached input | 37,996 | 36,307 |
| Output tokens | 5,920 | 7,578 |
| Shell commands | 14 | 10 |
| Command output bytes | 141,250 | 49,998 |
| Elapsed seconds | 207.463 | 253.103 |
| Passing citations | 0/6 | 4/6 |
| Graph invocations | 0 | 0 |

Total input decreased 45.09%, but uncached input only 4.45%; output increased 28.01% and elapsed time increased 22%. These are descriptive observations from one pair, not a billing or causal-savings claim. The prebuilt graph had 22 files, 203 symbols, and 508 edges; preparation took 3.498 seconds outside model execution.

The final explanations were checked against source: both describe dispatch, AST construction, global JVM relinking, partial-target suppression, edge insertion and lossless cached facts consistently with the implementation. However, baseline inserts ellipses into five verbatim quotations; Columbus does so once. Both cite cache codec definitions while omitting the requested cache-persistence statement from the cited range. These failures remain failures; the grader and answers were not edited after observation.

[Controlled evidence](controlled.json) includes both answers, every command and output hash, raw event hashes, prompts, invocation settings, source/engine/skill manifests, usage, and automatic grades. Raw event files and the runtime snapshot are retained locally under `.omx/observations/relational-pilot-b9d1072/`. No model reasoning traces are published. The invocation uses the documented [Codex non-interactive interface](https://developers.openai.com/codex/noninteractive); requested aliases are not backend attestations.

This task was still a small implementation-location exercise, despite requiring six connected stages. The available graph was not chosen. The next evaluation needs a genuinely repeated-context or caller-relationship task with a reviewed ground truth and an explicit contiguous-quote instruction applied equally to both arms. Predeclare that cohort before running it; do not selectively repeat this pair until it passes. The overall token-saving goal remains unproven.
