# Source access independent of resolved edges

The completed Requests trial obtained no resolved incoming calls for Session.send, SessionRedirectMixin.resolve_redirects and HTTPAdapter.send. Existing archive call context therefore returned no body for those declarations, and the model used separate line-range reads. The new archive-source command reads a declaration directly by its exact saved ID, without requiring an edge or SQLite index.

The command validates the complete gzip/XZ archive in one pass, reads the local source stably and checks its full-file hash. It returns only the stored declaration range, with physical line numbers, parser fidelity/partial metadata, and source-line pagination. Both JSON and text enforce their actual encoded byte budget; oversized individual lines fail rather than being truncated. The archive format and source-free relationship queries remain unchanged. This is source retrieval, not new resolution or runtime-dispatch evidence.

Tests cover an isolated function, both codecs and output formats, exact reconstruction across byte-limited pages, CLI operation without creating an index, stale source rejection, incomplete archive rejection even with limit=1, exact-ID requirements, invalid offset, oversized lines, and escaped text controls. Full engine suites passed 249 tests under both Java environments and root checks passed 53. The final no-index assertion passed in the focused three-test suite. Skill validation and wheel/ZIP installation verification passed.

On the frozen Requests archive, the three declarations above are retrieved in 1, 2 and 1 pages respectively at a 6000-byte text cap. Every returned line matches the complete source declaration and its recorded file hash; page spans and hashes are saved in requests-replay.json. No model was called. Neither this replay nor passing fixtures establish actual token savings or improved explanation accuracy. The previous nine completed comparisons remain unsuccessful under their original gates. A subsequent model observation must use newly frozen inputs and retain those failures.
